Step Counter

A simple JavaScript-based Step Counter project that tracks the number of steps taken by a user and calculates basic activity information.

Features
Add steps taken by the user.
Display the total number of steps.
Reset the step count.
Check whether the daily step goal has been reached.
Simple testbench for verification.
Files
Step-Counter/
├── stepCounter.js
├── testbench.js
└── README.md

How to Run

Make sure Node.js is installed on your computer.

Run the main program:

node stepCounter.js


Run the testbench:

node testbench.js

Example

If the user takes:

Morning: 2000 steps
Afternoon: 3000 steps
Evening: 2500 steps

The total is:

7500 steps


The default daily goal is 10,000 steps.

Technologies Used
JavaScript
Node.js
Expected Result

The program displays the total steps and indicates whether the daily step goal has been achieved.
